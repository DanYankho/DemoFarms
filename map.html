How to Use

Interactive Map

The map is fully interactive! Hover over any block on the map to see a popup with detailed information about that specific area, including harvest stats and block size.

Farm Summary

Use the 📊 button to view an overall farm summary. This opens a full-screen panel displaying aggregated statistics from all harvesting and irrigation records.

All Blocks

The 🌱 button shows a complete list of all blocks. It opens a full-screen panel with their key metrics from the Land and Harvesting sheets, making it easy to compare different blocks.
