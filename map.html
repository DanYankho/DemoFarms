How to Use

Exploring Blocks

Tap any block on the map to view detailed statistics. The map will zoom in and show block-specific data.

Farm Summary

Use the 📊 button to view overall farm statistics including total area, trees, and yields.

All Blocks

The 🌱 button shows a complete list of all blocks with their key metrics.

Search

Tap 🔍 to search for specific blocks by name. Results appear as you type.

Navigation

Use ← → buttons to cycle through blocks.
