How to Use

Exploring Blocks

Tap any block on the map to view detailed statistics including block size, land distribution, harvest weight, and irrigation details.

Farm Summary

Use the 📊 button to view overall farm statistics aggregated from Harvesting and Irrigation records.

All Blocks

The 🌱 button shows a complete list of all blocks with their key metrics from the Land and Harvesting sheets.

Search

Tap 🔍 to search for specific blocks by name (e.g., M1, M2). Results appear as you type.

Navigation

Use ← → buttons to cycle through blocks in order.
